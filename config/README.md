# Конфигурация

Приложение использует переменные окружения и не требует секретов для локального демо.

- `OLLAMA_URL` — адрес локальной Ollama; по умолчанию `http://127.0.0.1:11434`.
- `OLLAMA_MODEL` — локальная модель; по умолчанию `qwen2.5:7b`.
- `HEALTHSCREENING_API_KEY` — опциональный ключ защиты FastAPI.

Пример находится в `.env.example`. Не добавляйте реальные секреты или персональные данные в репозиторий.
