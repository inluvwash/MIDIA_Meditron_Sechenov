# Data Audit

Основной документ — DATA_AUDIT(1).md: финальная версия пользователя, без изменений.

- data/ — исходный датасет.
- spec/ — словарь переменных.
- config/ — признаки, единицы и технические границы, извлечённые из схемы проекта.
- tables/ — полные статистики, сравнение моделей, ошибки, подгруппы и проверочные предсказания.
- figures/ — корреляционные графики.
- models/ — метрики и метаданные. Бинарная модель не включена.
- scripts/research.py — воспроизведение расчётов.

## Повторный расчёт

В Python-окружении с зависимостями из requirements.txt, из папки распакованного архива:

```bash
python scripts/research.py
```

Результаты записываются в rerun_results/. Финальный аудит и исходные результаты не перезаписываются.
Упомянутые в отчёте границы screening/schema.py → LABS сохранены в config/audit_schema.json; исходники приложения для расчёта не нужны.
